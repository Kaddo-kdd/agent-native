# AN-075 — Validación con desarrolladores externos y reporte de fricciones

## Contexto y problema

La hipótesis central de INI-009 es que desarrolladores ajenos al proyecto puedan instalar, entender y usar Wasma de forma autónoma. Esta validación empírica revelará problemas de usabilidad o documentación antes del anuncio masivo.

## Criterios de aceptación

- AC-01: Se diseña el protocolo de prueba piloto con tareas claras: instalación, ejecución de tutorial, modificación de un componente y evaluación de reglas.
- AC-02: Se reclutan entre 5 y 10 desarrolladores de perfiles diversos sin experiencia previa en Wasma.
- AC-03: Se registran métricas observables: tasa de finalización autónoma, tiempo hasta el primer componente y errores encontrados.
- AC-04: Se publica un informe consolidado de hallazgos y fricciones con propuestas priorizadas para iteraciones posteriores.
