# AN-076 — Publicación oficial v0.1.0 y cierre de INI-009

## Contexto y problema

Work Item de coordinación final para la primera entrega pública v0.1.0 de Wasma tras completar todas las verificaciones técnicas, de seguridad y de adopción.

## Criterios de aceptación

- AC-01: Los paquetes binarios firmados y catálogo de hashes están publicados en GitHub Releases bajo el tag `v0.1.0`.
- AC-02: Las notas de versión, limitaciones conocidas y compatibilidad están publicadas en el portal y en GitHub Releases.
- AC-03: Los resultados del piloto de adopción están documentados y los bloqueos críticos resueltos.
- AC-04: Se cuenta con la autorización humana explícita para la liberación pública.
- AC-05: Se evalúa y formaliza el cierre de INI-009 con `kaddo_complete_initiative`.
